# Assumptions, logic and validation of the lead generation plan

## Variables
| Symbol | Meaning |
|---|---|
| **P** (portfolio multiplier) | Market coverage from the product range: 0.2 per kit, from 0.2 (one kit) to 1.0 (five kits). **Assumption:** the planned product launches happen |
| **T** (trust factor) | A fixed coefficient (0.4) for brand maturity and technical validation in the current market, taking the top competitor as T = 1 (100%) |
| **CS%** (channel strength) | The probability that a qualified deal closes, based on the interaction quality of that channel and historical analysis |
| **Capacity** | P x T. For example 0.8 x 0.4 = 32%, the highest close rate the plan allows any channel to assume |

## Formula
Revenue target / average order value = wins needed. Example: $48,000 / $4,000 = 12 wins.
Exception: OEM orders, where the order value is small (about $500 per unit).
**Assumption:** each deal is a unique customer.

## Validation
1. **P x T logic.** Each channel's required CS% is below the 32% capacity, so the plan is mathematically conservative and carries low risk of failure.
2. **CRM close ratio.** Last year's deal close rate was about 20%. This year's rate fell to about 12%, mainly because a bulk update of last year's deals changed the base, which should lift the average back to about 27%. Many deals in both years were created before the product offering existed, so the lower rate cannot be read as weak selling.
3. **Decision.** Use logic A (P x T) and set the benchmark close rate at 32%.

## What is assumed and what is measured
- **Assumed:** that the planned launches happen (P), the trust factor (T), and one customer per deal.
- **Measured:** CRM deal close rates and channel interaction history.
- **Replaced as data arrives:** each month, plan against actual replaces assumed close rates with real ones.
