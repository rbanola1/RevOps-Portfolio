# Password manager rollout

**Why:** shared and personal credentials were kept in browsers, spreadsheets and messages. A company password manager gives each person a private vault, gives the team a shared vault with approval, and keeps access recoverable when staff change.

## Vault model
| Vault | Who | Rules |
|---|---|---|
| Employee vault (private work vault) | One person | Admins cannot browse it, there is no "view all" screen and no silent monitoring |
| Shared vault | The team | Holds shared logins, payment cards and company accounts; entries are added only after executive approval |

Admins can reach an employee vault only through a deliberate action: account recovery, an employee leaving, or a business emergency.

## Setup for each person
1. Create the account with the work email and set a strong **master password**. It cannot be reset, so memorise it.
2. Generate the **secret key**. It stays on the device or in a locked folder; IT locks the folder after executive approval.
3. Save the **emergency kit** (secret key; the master password is optional) in the locked folder; keep a backup in a locked commercial operations subfolder.
4. Turn on two-factor authentication (optional but recommended) and install the browser extension.

## Moving passwords in
- **Import:** export saved passwords from the browser as a CSV, import into the employee vault, then delete the browser-saved logins and the CSV file.
- **Manual:** add items one at a time (logins, cards). A saved item can be shared with a person for a set time through a link.

## Process
1. Set up the manager and memorise the master password.
2. Save the secret key and emergency kit in the locked folder.
3. Put work logins in the employee vault.
4. Put shared logins and cards in the shared vault after approval.
5. Back up the emergency kit in the commercial operations folder.
6. Use the recorded walkthrough for questions.

## Rules
- No password, key or token is written in documents, tickets, chats or code; documentation says only where it is stored.
- Departures: the manager's owner recovers shared access the same day.
- Reviews: shared vault membership is checked each quarter.
