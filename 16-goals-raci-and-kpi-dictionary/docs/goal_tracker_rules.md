# Goal tracker rules

| Field | Rule |
|---|---|
| Name | One line, starting with a verb or a result |
| Type | Company goal, department goal, commercial system, operations goal or other project |
| Priority | 1 high, 2 medium, 3 low; no more than half of all items may be priority 1 |
| Lead | One named role; supporting teams listed separately |
| Due | Quarter and year |
| Status | Not started, On track, Under review, Completed, Cancelled |
| Parent | Each project names the goal it serves; a project with no parent is questioned |
| Note | One line: the reason for any change of status or date |

## Rules
- Status is updated before the weekly meeting, not during it.
- Cancelled items stay with the reason and the condition to restart (for example "resume when a finance manager is hired").
- Dates change only with a note.
- A goal that is under review for two cycles is escalated for a decision: continue, change or cancel.
