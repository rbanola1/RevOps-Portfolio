# Marketplace listing requirements and RFI response kit

## Why
Each marketplace or procurement platform asks for the same product facts in a different format. Filling them from memory causes errors that show up as mismatches in the catalog audit.

## Listing requirements checklist (per platform)
| Field | What to check |
|---|---|
| Unit of measure | The platform's own code list, mapped from the master unit (for example each, kit, vial) |
| Pack size and description | Same wording as the master; length limits respected |
| Price | From the approved price list; currency and price-validity dates as the platform requires |
| Lead time | In days, in the platform's format |
| Classification codes | Taken from the master and from the logistics owner; commercial staff do not edit them |
| SKU or part number | Identical to the master; one SKU per product on every platform |
| Media | Image and document formats, sizes and file names as the platform requires |
| Compliance | Restricted-product flags, safety data sheets, country-of-origin and shipping restrictions |
| Process | Staged upload, review, then publish; a record of the date each step happened |

## Process
1. Read the platform's own guidelines first and note its format rules.
2. Build the platform sheet from the master; do not retype values.
3. Run the cross-platform check (SKU, price, pack size, lead time) before submitting.
4. Submit, track the status, and record the live date in the partner log.
5. Re-check after any price or product change in the master.

## RFI and vendor questionnaire response kit
| Component | Contents |
|---|---|
| Answer library | Approved answers to common questions: company profile, products, quality, shipping, returns, insurance, data security, sustainability, references |
| Document pack | Company overview, quality statements, insurance certificate, standard terms, product data sheets |
| Owners | Commercial operations drafts; quality, finance and legal approve their sections |
| Review | Every answer dated; reviewed twice a year |
| Response time | Target five business days for standard questionnaires |
| Rules | Never enter bank, tax or credential details in a form; the finance team supplies and submits them |

## Measures
- Listings with zero mismatches against the master at launch.
- Days from platform request to live listing.
- Share of RFI questions answered from the library without new drafting.
