# Tagging taxonomy

## Themes (nine)
| Theme | Use when the customer is talking about |
|---|---|
| Product performance | How the product behaved in their experiment |
| Documentation | Protocols, data sheets, certificates, instructions |
| Pricing and quotes | Cost, discounts, quote process |
| Delivery and logistics | Shipping, timing, packaging, cold chain |
| Application support | How to use or adapt the product |
| Competitor information | What they use or have evaluated elsewhere |
| Product request | Something they want that we do not offer |
| Testimonial | Positive statement they are willing to be quoted on (permission requested) |
| Objection: evidence or data | A reason not to buy yet, such as missing validation data |

## Segments (ten)
Academia · Biotech · Pharma · CRO · CGT developer · Hospital · Core facility · Nonprofit foundation · Government · Distributor

## Other tags
- **Product area:** cell line A, cell line B, media kit C, compound sets, growth medium, custom services.
- **Competitor:** named vendor or in-house protocol.
- **Sentiment:** -2 very negative, -1 negative, 0 neutral, +1 positive, +2 very positive.
- **Source:** booth conversation, support ticket, survey, email, webinar question.

## Rules
- One primary theme per record; mention a second theme in the summary.
- Evaluation comments belong under product performance or documentation, not a separate evaluation tag.
- Competitor information is a tag in addition to the main theme when a competitor is named.
- Testimonials are always marked with permission status before anyone reuses them.
