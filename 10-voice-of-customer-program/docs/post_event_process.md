# Post-event process

## Before the event
- Set a goal for VOC: how many conversations, which segments and questions matter most (for example evidence needed for a product, interest in a new product area).
- Give everyone at the booth the capture form and the theme list.
- Prepare three standard questions to ask in every conversation.

## At the event
- Enter each meaningful conversation the same day, even as a short note; clean it up within 48 hours.
- Scan or note contacts so each VOC record links to a contact.

## Within 48 hours
- Create all VOC records with theme, segment, sentiment and action.
- Send follow-ups: protocols, data packs, quotes, sample offers.
- Mark testimonials and request permission.

## Within one week
- Run the dashboard: entries by theme and segment, sentiment by product, competitor mentions, ranked requests.
- Write a one-page event summary: top five insights, top objections, leads and deals expected, recommended actions.

## Within one month
- Compare events: entries, leads, deals and useful intelligence per entry; decide which shows to repeat, change or drop.
- Review actions: closed, in progress, no owner.

## Measures
Entries per event, share with an action, share followed up within 48 hours, lead rate, deal rate, objections resolved, requests sent to product management.
