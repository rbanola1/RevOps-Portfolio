# Backup operator and training

## Why
If only one person can process orders, any absence delays shipments and revenue. The goal was two people able to run the process end to end.

## Plan
| Step | Description |
|---|---|
| 1. Record | Record a video of a full order from email to shipment, with narration |
| 2. Write | Keep the SOP and a one-page checklist beside the video |
| 3. Shadow | The backup watches live orders for one week |
| 4. Reverse shadow | The backup runs live orders with the main operator watching for one week |
| 5. Solo | The backup runs orders alone for a week; the main operator reviews the results |
| 6. Cover | The backup covers planned leave; the process is reviewed afterwards |

## Handover page (one page)
- Where the order mailbox, the ERP and the shipping portal are, and who to contact for each.
- The ten SOP steps with the three most common mistakes.
- Exceptions and who approves them.
- What to do if the ERP is down: manual order sheet, then entry once the system is back.
- Credentials are in the company password manager; none appear in this document.

## Measures
- Number of people who can complete an order end to end: two or more.
- Orders processed by the backup each quarter, to keep the skill current.
- Errors per hundred orders, by operator.
