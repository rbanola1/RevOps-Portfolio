# Quote process in the CRM

**Why:** a proper record of every quotation shared, uniform pricing, product names and SKUs, pre-checked terms, and visibility for the team.

## Steps
1. Open the right deal and check it is associated with the right company and contacts (at most two contacts on the quote).
2. Add a quote from the deal's quotes card and work through the six steps.
3. Check the preparer details; add a phone number so the client can call with questions.
4. Review line items, add any discount, and add shipping as a one-time fee when needed. Check the total.
5. Choose "no signature" (online payments are not enabled). Ask the client how they will buy: web order using a discount code, or purchase order. For a web order, get the web code from the web owner first and include it.
6. Pick the current approved quote template and a **30-day expiry**. Leave purchase terms alone: the standard terms already state net 30.
7. Review the final step for pricing or contact errors, then create (to publish) or save (to finish later).
8. Share the quote link, or download it and attach it to an email.

## Best practices
- Always associate the deal with the right company, line items and contacts.
- Always ask how the client will order.
- Always set the 30-day expiry.
- The first time anyone creates a quote, run it on the test deal in the test account and get it approved by the team; never create a new deal for a test.
