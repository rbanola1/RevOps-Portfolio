# Quota setting

## Method
| Step | Description |
|---|---|
| 1. Top-down | Company target divided by each territory's share of potential |
| 2. Bottom-up | Expansion from current customers + open pipeline x win rate + capacity for new-account wins, per rep |
| 3. Compare | Gap between the two shows whether the target is supportable |
| 4. Blend | Recommended quota = 60% top-down + 40% bottom-up |
| 5. Simulate | Run 4,000 simulated years with normal variation to see how many reps reach 100% and how many fall below 70% |
| 6. Adjust | If fewer than about 55% would reach quota, lower the blend weight on top-down or raise capacity |

## Synthetic result
| Measure | Value |
|---|---|
| Company target | $3.80M |
| Bottom-up estimate | $3.44M |
| Recommended quotas, total | $3.66M |
| Reps reaching 100%: top-down only | 49% |
| Reps reaching 100%: recommended blend | 55% |
| Reps reaching 100%: bottom-up only | 66% |

## Rules
- Quotas are set before the year starts and shared in writing with the territory and plan.
- Mid-year changes only for a new product, a partner change or a territory change, with the reason recorded.
- A gap between the company target and the sum of quotas is shown to leadership and covered by a named plan (new partner, new product, or marketing programme), not hidden inside rep quotas.
- Ramp: a new rep has a reduced quota for the first two quarters.
